# Disney-Express
Bienvenue dans l'aventure Disney Express ! Nous avons élaboré un système d'authentification pour un parc d'attractions Disney fictif en ajoutant un système de favoris. Notre objectif est de permettre aux utilisateurs connectés d'ajouter des attractions à leur liste de favoris. Outils utilisés : PHP, Fichier CSV
